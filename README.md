# BUILD 대학교 — 공부한 시간이 학점이 되는 곳

대학생 공부 집중 서비스입니다. **사이트**에서 공부 타이머·학점·학교 대항전을 쓰고, 원하면 **확장 프로그램**을 설치해서 다른 탭에서 하는 공부까지 자동으로 판별합니다.

| | 사이트만 | 사이트 + 확장 프로그램 |
|---|---|---|
| 설치 | 없음 (주소로 접속) | 확장 프로그램 추가 |
| 순공 측정 | 사이트 탭을 열어 둔 동안만 | 공부로 판별된 탭에 있는 동안 (인강·LMS·백준·노션…) |
| 딴짓 | 사이트 탭을 30초 넘게 벗어나면 이탈 1회 | 딴짓 탭(웹툰·SNS·OTT…)에 30초 넘게 있으면 이탈 1회 |
| 계정 | 사이트에서 가입 | 사이트를 열면 같은 계정으로 자동 연결 |

```
BUILD/
├─ server/                  사이트 + 대항전 서버 (Node 18+, 설치할 패키지 없음)
│  ├─ server.js
│  └─ public/
│     ├─ index.html, app/   사이트 (공부하기 · 내 기록 · 대항전 · 캠퍼스 · 설정)
│     ├─ board.html         발표용 실시간 전광판  (/board)
│     └─ admin.html         학교 등록 요청 관리   (/admin)
├─ extension/               확장 프로그램 (선택)
│  ├─ lib/                  사이트와 함께 쓰는 공용 코드 (학점·리그·학교 목록·대시보드 화면)
│  └─ site-bridge.js        사이트 ↔ 확장 프로그램 자동 연결
└─ render.yaml              Render에 올릴 때 쓰는 설정
```

## 1. 내 PC에서 실행

```bash
node server/server.js
```

- 사이트: **http://localhost:8787**  → 학교·닉네임으로 가입하면 바로 공부 타이머가 시작돼요.
- 전광판: http://localhost:8787/board
- 학교 등록 요청 관리: http://localhost:8787/admin (서버 PC에서만 열림)
- 기록 전부 지우고 시작: `node server/server.js --reset`
- 같은 와이파이의 친구와 대결: `node server/server.js --lan` → 친구는 `http://내PC의IP:8787` 로 접속

### 확장 프로그램 (선택)
1. `chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → `BUILD/extension` 폴더 선택
2. 사이트(`http://localhost:8787`)를 열면 **사이트 계정으로 자동 연결**돼요. 연결되면 사이트 상단에 "확장 프로그램으로 자동 판별 중"이 떠요.
3. 이후 사이트의 공부 시작/멈추기 버튼은 확장 프로그램을 켜고 끄고, 시간은 확장 프로그램이 잽니다. (사이트는 닫아 둬도 돼요)

## 2. 인터넷에 올리기 (누구나 주소로 접속)

Render 기준 (다른 Node 호스팅도 같은 방식):
1. 이 폴더를 GitHub 저장소에 올려요.
2. Render → New → **Blueprint** → 저장소 선택 (`render.yaml`을 자동으로 읽음)
3. 배포가 끝나면 `https://build-univ.onrender.com` 같은 주소가 생겨요. 이 주소가 사이트예요.
4. 관리 화면: `https://…/admin?key=ADMIN_KEY값` (Render 환경변수에서 확인)

알아둘 점
- 무료 요금제는 서버가 재시작되면 `db.json`(점수·가입 기록)이 지워져요. 계속 쓰려면 Render 디스크를 붙이고 `DATA_DIR`을 그 경로로 지정하세요.
- 무료 요금제는 한동안 접속이 없으면 잠들고, 다음 접속 때 깨어나느라 시간이 좀 걸려요. 발표 직전에 한 번 열어 두세요.
- 확장 프로그램을 배포 주소와 쓰려면 확장 프로그램 설정 › 랭킹·계정 › 대항전 서버에 그 주소를 넣고 권한을 허용하세요. (크롬 웹 스토어에 올릴 때는 기본 주소를 배포 주소로 바꿔서 올리면 돼요)

## 3. 측정 방식

**사이트(웹 타이머)**
- 공부 시작 후 이 탭을 보고 있는 동안만 순공. 다른 탭·프로그램으로 가면 멈추고, 30초 넘게 비우면 이탈 1회
- 책으로 공부할 때는 탭만 켜 두면 되고, 25분(설정 가능) 동안 입력이 없으면 "아직 공부 중인가요?"를 물어봐요. 5분 안에 답이 없으면 멈춰요.

**확장 프로그램**

| 상태 | 언제 | 순공 |
|---|---|---|
| 공부 중 | 공부로 판별된 탭 | 더함 |
| 판별 대기 | 유튜브처럼 애매한 탭 | 멈춤. 공부로 판별·정정되면 기다린 시간까지 소급 |
| 딴짓 | 웹툰·SNS·OTT 등 | 멈춤. 30초 넘으면 이탈 1회, 2분 넘으면 알림 |
| 자리 비움 | 입력이 5분(설정) 없음 | 마지막 입력 시각까지만 인정 (공부 탭에서 강의 소리가 나면 계속) |

판별 순서: 내가 정한 사이트 → 정정 기억 → 기본 규칙 목록 → AI 판별(설정에 API 키를 넣은 경우, 도메인+제목만 전송) 또는 제목 키워드

## 4. 학점 · 대항전
- 학점: 시간 점수 80(주 25시간이면 만점) + 집중도 점수 20(공부 1시간당 이탈이 적을수록) → 95↑ A+ … 60 미만 F, 매주 월요일 0시 확정. 확정될 때마다 캠퍼스에 한 층
- 대항전: 순공 1분 = 학교 1점, 25분 연속 집중 콤보 +5점, 매일 0시 리셋, 총점과 1인 평균 두 가지 순위
- 데모 학교: 사용자가 적을 때 화면이 비지 않도록 다른 학교 점수를 시간대별로 시뮬레이션해요(전광판에서 '실사용자' 표시가 없는 학교). `DEMO=0`으로 끄면 실사용자만 남아요.

## 5. 학교 이름 확인
- 전국 4년제 대학 목록(약 190곳)에서 검색해 골라요. `충북대`, `CBNU`, `카이스트`처럼 줄임말을 넣어도 공식 이름 하나로 묶여요.
- 목록에 없는 학교는 **등록 요청**으로 가입 → 승인 전까지는 기록·학점만 쌓이고 대항전 점수엔 안 들어가요. 같은 학교를 3명이 요청하면 자동 승인, `/admin`에서 승인·거절·합치기
- 학교 목록: `extension/lib/schools.js`

## 6. 계정 · 데이터
- 비밀번호 대신 브라우저에 계정 키가 저장돼요. 다른 기기에서 쓰려면 설정 › 다른 기기에서 쓰기 › **로그인 코드**를 새 기기에 붙여 넣어요.
- 서버로 보내는 것: 하루 순공 합계, 시간대별 순공, 콤보 수, 이탈 횟수, 지금 공부 중인지, 학교·학과·닉네임
- 보내지 않는 것: 방문 기록, 페이지 본문, 주소 경로·검색어
- 서버 부정 방지: 지난 보고 이후 흐른 시간보다 순공이 더 늘어날 수 없음

## 7. 자동 테스트 (Playwright)

```bash
npm install                      # 테스트용 Playwright 설치 (처음 한 번)
npx playwright install chromium  # 테스트용 브라우저 설치 (처음 한 번)
npm test                         # 전체 테스트 (약 1분)
npm run test:quick               # 브라우저 없이 규칙·서버만 (몇 초)
```

| 파일 | 확인하는 것 |
|---|---|
| `tests/unit.test.mjs` | 탭 판별 순서(내 목록 → 정정 → 기본 규칙 → 제목), 학점(시간 80 + 집중도 20), 학교 줄임말, 점수 계산 |
| `tests/server.test.mjs` | 가입·학교 자동 승인, 기록 부풀리기 차단, 잘못된 토큰·지난 날짜 거부, 랭킹에 토큰·방문 기록이 안 나가는지 |
| `tests/web-timer.test.mjs` | 실제 브라우저에서 가입 → 탭을 보는 동안만 측정, 벗어나면 멈춤, 30초 이탈, 25분 무입력 확인 창, 서버 보고 |
| `tests/extension.test.mjs` | 실제 크롬에 확장 프로그램을 올려 공부 탭/딴짓 탭 구분, 유튜브 제목 판별, 정정, 30초 이탈, 공부 모드 켜기·끄기 |

- 테스트는 임시 폴더에 기록을 저장하는 서버를 따로 띄우므로 실제 기록(`server/data/db.json`)은 건드리지 않아요.
- 공부·딴짓 사이트는 인터넷 대신 가짜 페이지로 응답하므로 오프라인에서도 돌아가요.
- 웹 타이머 테스트는 Playwright의 가짜 시계로 시간을 빨리 감아서, 25분짜리 상황도 몇 초 만에 확인해요.
